# Мои финансы — установка на iPhone

## Бесплатная установка через GitHub Pages
1. Распакуйте архив на компьютере. Внутри должны быть index.html, app.js, sw.js, manifest.json и два PNG-файла.
2. Войдите на https://github.com/ и создайте новый публичный репозиторий, например `my-finance`.
3. Через Add file → Upload files загрузите содержимое архива в корень репозитория (не папку целиком). Нажмите Commit changes.
4. Откройте Settings → Pages → Build and deployment. Source: Deploy from a branch. Branch: main, / (root). Нажмите Save.
5. После завершения публикации откройте ссылку, показанную в Settings → Pages, например https://ВАШ-ЛОГИН.github.io/my-finance/.
6. На iPhone откройте эту ссылку в Safari. Нажмите «Поделиться» → «На экран Домой», включите «Открыть как веб-приложение», если такой переключатель есть, и нажмите «Добавить».
7. Запустите приложение с новой иконки при наличии интернета. Затем закройте и снова откройте в авиарежиме, чтобы проверить офлайн-режим.

## Использование
- Главная: нажмите большую кнопку +. Расход выбран по умолчанию. Свайп по полосе выбора или нажатие вкладки переключает тип операции.
- Долги: укажите направление, имя, сумму и необязательный срок. Нажмите на запись для полного или частичного погашения.
- Компенсации: откройте расход и выберите «Скомпенсировано» или частичный возврат. Отдельные возвраты можно отменить.
- Настройки: создавайте, переименовывайте и скрывайте категории. История скрытых категорий сохраняется. Валюта единая, без конвертации.
- Статистика: расходы и компенсации учитываются по датам фактических операций. Возвраты долгов не считаются доходом или расходом.

## Данные и резервные копии
Данные сохраняются в IndexedDB на устройстве. Код не отправляет операции на сервер. Публичный репозиторий содержит только код, не загружайте туда резервные копии. Данные в Safari и установленном веб-приложении могут быть разделены; лучше вводить данные после установки.
В настройках нажмите «Экспорт JSON», сохраните файл в приложении «Файлы». Для восстановления нажмите «Импорт JSON» и выберите копию. Импорт заменяет текущую базу. CSV предназначен для просмотра, не для восстановления.
Очистка данных сайтов, удаление приложения, смена адреса сайта или действия системы могут привести к потере локальных данных. Регулярно сохраняйте JSON. Файл резервной копии не зашифрован.
Face ID, фоновые уведомления и синхронизация не реализованы. Приложение не является банковским сервисом.

## Проверка на компьютере (необязательно)
В папке проекта выполните `python -m http.server 8000`, откройте http://localhost:8000. Не запускайте index.html непосредственно из файлового менеджера для проверки PWA: сервис-воркер требует HTTPS или localhost.
