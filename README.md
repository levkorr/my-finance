# Мои финансы

**Мои финансы** — бесплатное приложение для учёта личных расходов, доходов, долгов и компенсаций. Оно позволяет быстро записывать операции, контролировать траты и отслеживать возврат денег без регистрации и подключения к банковским аккаунтам.

Приложение работает прямо в браузере и может быть установлено на iPhone как PWA без App Store. После первоначальной загрузки доступна работа без интернета.

**[Открыть приложение →](https://levkorr.github.io/my-finance/)**

## Возможности

### Расходы и доходы

- Быстрое добавление операций через кнопку «+».
- Указание суммы, даты, категории и комментария для расходов.
- Учёт доходов с указанием источника поступления.
- История операций, сгруппированная по дням, с отображением суммы расходов за каждый день после компенсаций.
- Отображение расходов в формате «Категория — Комментарий».
- Редактирование и удаление существующих операций.

### Долги

- Учёт выданных и полученных долгов.
- Указание имени человека, суммы и необязательного срока возврата.
- Отображение просроченных и закрытых долгов.
- Полное и частичное погашение с сохранением истории возвратов.

### Компенсации расходов

Если покупка была оплачена за другого человека или за неё должны вернуть деньги, откройте расход и нажмите «Должны скомпенсировать». Операция появится в соответствующем разделе вкладки «Долги».

- Полная и частичная компенсация с указанием даты возврата.
- Автоматический пересчёт фактических расходов и ожидаемой суммы возмещения.
- Полностью возмещённые операции остаются в истории с отметкой «Скомпенсировано».
- Возможность отменить ожидание компенсации или ранее внесённый возврат.

Ожидание компенсации само по себе не уменьшает расходы: учитываются только фактически возвращённые деньги.

### Статистика

- Общая сумма расходов, доходов и компенсаций.
- Чистые расходы за выбранный период.
- Распределение расходов по категориям до компенсаций.
- Периоды: сегодня, последние 7 дней, текущий месяц, текущий год и всё время.

Возвраты учитываются по дате фактического поступления. Долги и их погашение не включаются в статистику расходов и доходов.

### Настройки и интерфейс

- Создание собственных категорий, изменение названий и выбор иконок.
- Возможность скрывать ненужные категории без удаления их истории.
- Выбор валюты (без автоматической конвертации сумм).
- Светлая и тёмная темы в соответствии с настройками устройства.
- Центральное всплывающее окно добавления операций с плавной анимацией из кнопки «+» и закрытием по нажатию вне окна.
- Переключение типов операций нажатием или свайпом.

## Установка на iPhone

1. Откройте [приложение](https://levkorr.github.io/my-finance/) в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой».
4. Включите «Открыть как веб-приложение», если доступно.
5. Нажмите «Добавить».
6. Запустите приложение с главного экрана при включённом интернете для первоначальной загрузки.

После этого приложением можно пользоваться с главного экрана, в том числе без интернета. Для проверки автономной работы откройте его в авиарежиме после первой загрузки.

## Хранение данных и резервные копии

Все финансовые данные хранятся локально на устройстве в IndexedDB. Приложение не отправляет операции на сервер, не требует аккаунта и не синхронизируется с другими устройствами.

В разделе «Настройки» доступны:

| Функция | Назначение |
| --- | --- |
| Экспорт JSON | Полная резервная копия операций, категорий и компенсаций |
| Импорт JSON | Восстановление данных из резервной копии |
| Экспорт CSV | Выгрузка операций для просмотра и анализа в табличных редакторах |

> [!IMPORTANT]
> Импорт JSON заменяет текущую базу данных. Перед импортом и обновлением приложения рекомендуется сохранять резервную копию. Очистка данных сайта, удаление приложения или смена его адреса могут привести к потере записей. Хранилища Safari и установленного PWA могут быть разделены. JSON-файлы не зашифрованы — не публикуйте их в открытом репозитории.

## Для разработчиков

### Технологии

Проект представляет собой статическое веб-приложение без серверной части и внешних библиотек.

| Технология | Назначение |
| --- | --- |
| HTML5, CSS3 | Разметка и адаптивный интерфейс |
| JavaScript (Vanilla JS) | Логика операций, статистика и анимации |
| IndexedDB | Локальное хранение данных |
| Service Worker | Кэширование ресурсов и автономная работа |
| Web App Manifest | Установка приложения в режиме PWA |
| SVG | Иконки навигации и кнопки добавления |
| GitHub Pages | Публикация приложения |

### Структура проекта

```text
my-finance/
├── index.html      # Разметка и стили
├── app.js          # Логика приложения и работа с данными
├── sw.js           # Service Worker и кэширование
├── manifest.json   # Конфигурация PWA
├── icon-192.png    # Иконка приложения 192 × 192
├── icon-512.png    # Иконка приложения 512 × 512
└── README.md      # Документация
```

### Локальный запуск

```bash
git clone https://github.com/levkorr/my-finance.git
cd my-finance
python3 -m http.server 8000
```

Откройте [http://localhost:8000](http://localhost:8000) в браузере. Установка зависимостей и сборка не требуются. Для работы Service Worker необходим HTTPS или localhost; открытие `index.html` напрямую через `file://` не подходит для проверки PWA.

### Хранение и формат данных

- База IndexedDB: `my-finance`, хранилище: `data`, ключ состояния: `state`.
- Текущая версия формата JSON: `2`.
- Суммы хранятся в целых числах в сотых долях денежной единицы (для рублей — в копейках).
- Даты операций хранятся в формате `YYYY-MM-DD`.
- Типы операций: `expense`, `income`, `debt`.
- Возвраты и компенсации хранятся в массиве `adjustments`, ожидание компенсации — в поле `expectedCompensation`.

### Публикация и обновление

Для развёртывания на GitHub Pages разместите файлы приложения в корне репозитория и выберите **Settings → Pages → Deploy from a branch → main → / (root)**.

При изменении приложения обновите соответствующие файлы и измените версию кэша в `sw.js`, чтобы установленные PWA получили новые ресурсы. Сохраняйте совместимость с существующим форматом данных и прежним адресом сайта.
